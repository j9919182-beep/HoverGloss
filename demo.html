句子优先语境测试

The investment generated a high return last year.

The function will return the first matching value.

Run the SQL query and inspect the first row.

The river runs through the center of the city.

低匹配时的句意复核

可先在设置中启用本机对齐模型，再悬停下面的 capital 或 key。译文随浏览器模型而异；如果对应片段不可靠，卡片应保留原候选并标明“待确认”。

The firm needs to raise capital for expansion.

The key metric improved this quarter.

短语内单词释义

悬停下面的 Commission：应显示“委员会”，并附上“European Commission → 欧盟委员会”。

The European Commission president addressed the parliament.

对照悬停下面的 commission：应保留“佣金”，不套用机构名称。

The sales commission increased this year.

下面是未写入短语词库的试验例句：启用本机对齐后悬停 Parliament。若模型能可靠定位，应给出“议会”；否则应显示短语义或“暂无法确定”，不应把孤立词义冒充确定结果。

The European Parliament debated the proposal.

下面两例没有写入专用短语词库：悬停 prime 或 credit。当模型只能确认整短语时，应显示“短语义”，不能把“总理”“信用卡”当成单词的独立释义。

The prime minister spoke at the meeting.

Her credit card expired yesterday.

再悬停下句的 stock：若整句译为“评估局势”一类意译，应展示短语义或待确认，而非把“股票”当成句中词义。

We need to take stock of the situation before deciding.

数据分析术语

Write a query to retrieve rows from a table and aggregate sales by category.

The dashboard highlights a trend, an outlier, and customer retention.

A primary key uniquely identifies each row, while a foreign key connects two tables.

The database uses an index to retrieve the result set efficiently.

拖拽翻译句子和自然段

SQL allows analysts to retrieve, filter, aggregate, and combine data from relational databases. A well-written query should be accurate, readable, and consistent with the definition of each business metric.

Before drawing a conclusion, analysts should check missing values, duplicated records, join keys, and the time range of the dataset. These checks reduce the risk of producing misleading results.

return：返回值与投资收益

The function will return a value after the query is complete.

The investor expects a higher annual return from the asset.

order：订单、排序与顺序

The customer placed a new order for the product.

Use ORDER BY to sort the query result.

The order of execution determines the final result.

stock：库存与股票

The warehouse has insufficient stock for the next shipment.

The stock market opened higher after the announcement.

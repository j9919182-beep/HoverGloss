# HoverGloss v0.9.31 Preview

这是 HoverGloss 的首次公开预览：在网页或 PDF 阅读时，就地理解英语、法语词句，并把词义、原句和来源一起留在学习库。

## 本版内容

- 网页悬停和选中翻译，提供单词/短语与整句参考。
- PDF 多文件、目录和续读，尝试补全跨页句子；扫描页可手动 OCR。
- 独立英语、法语学习库：发音、笔记、复习与导入导出；法语有离线基础语法提示。
- 支持平台搜索框的中文转英文，以及可选的 YouTube / B站英文 CC 双语字幕。

## 安装

下载附件 `HoverGloss-v0.9.31-preview.zip`，解压后在 Edge / Chrome 扩展管理页开启开发人员模式，加载直接包含 `manifest.json` 的文件夹。普通试用无需 Node.js。

完整源码附件为 `HoverGloss-v0.9.31-source.zip`；`SHA256SUMS.txt` 可用于核对文件。首次使用按 README 准备本机翻译并在当前网站启用。浏览器本机 API 不可用时，可自行配置 AI 服务商；相关费用与数据处理由服务商决定。

## 预览范围

尚未上架扩展商店。译文、词语对齐、PDF 排版识别、离线法语语法和自动字幕均可能有误；无 CC 听音是实验功能。后台字幕可能延迟，部分网站/设备不支持。

测试覆盖逻辑、界面与真实扩展加载；其中翻译、字幕夹具使用模拟数据，不代表真实模型准确率或所有网站兼容性已验证。欢迎通过 Issues 提供脱敏的复现步骤。

# HoverGloss · 极简悬译

![HoverGloss 图标](icons/icon128.png)

一个面向英语、法语精读的 Chrome / Edge 扩展。它不整页替换文本：你在指定网站按键悬停或主动选中内容后，释义才会浮现。当前版本是 **v0.9.31 预览版**，尚未发布到浏览器扩展商店。

## v0.9.31：PDF 跨页句子

文字层 PDF 的页末、页首会按阅读顺序检查相邻页正文，尝试补全被分页截断的句子。在前一页或后一页悬停，均可得到补全后的句子和正确的目标词位置。拼接会避开页眉、页码和其他栏目，并在完整句子、明显标题或新段落处停止；复杂、无法确认的布局保持当前页语境。

仅按需读取当前页及前后相邻页，不渲染相邻页；每个打开文件最多缓存 6 页布局，关闭文件释放。跨页语境不改变“整理当前页”的复制范围。相邻页没有文字层或无法读取时，当前页仍可正常使用；不会自动启动 OCR。

## v0.9.30：语境、字幕与学习库恢复

- 本机句译保留完整句子；长句对齐围绕所选词取片段、重算位置并生成配对译文，结果仍需整句译文支持，避免句尾目标被截断。
- 切换听音模式会取消尚未完成的 CC 启动任务。弹窗显示真实的等待英文 CC、翻译中或失败状态。
- 字幕显示模式、字号、比例、底距、背景、停留时间及全屏偏好保存在本机，YouTube 与 B站分别记忆；读取偏好不会自动启动字幕。
- 学习库新增“导入记录”：选择对应语言的 HoverGloss JSON 备份，先预览再确认合并。重复语境补充短语并保留已有释义、笔记和复习进度；新记录恢复备份进度。语言不符、格式异常或超限时拒绝写入。
- 字幕开关、取消、偏好、学习库导入测试接入自动检查；弹窗和导入界面加入独立浏览器检查。

导入文件最多 12 MB，每个语言库仍最多 1000 条、6 MiB。建议导入前先导出当前记录。

## v0.9.29：字幕开关与精简界面

在 YouTube / B站支持的视频页，扩展弹窗新增“自动双语字幕”开关：开启会准备本机英中翻译并读取英文 CC，关闭会停止；无需先打开侧栏。状态随当前视频会话同步，不会跨视频自动开启。首次若浏览器要求页面点击，会提示在视频画面点击一次“开始双语字幕”；模型失败会复原关闭状态。YouTube 尝试开启 CC，英语字幕仍由用户选择。听音识别仍在字幕设置中单独授权。

弹窗按悬停、学习、搜索、字幕排列。快捷键、搜索高级选项、字幕字号与使用说明默认折叠；“字幕设置与记录”保留详细控制和临时字幕历史。收起弹窗或面板不停止已开启的画面 CC 翻译。本节替代 v0.9.28 必须先打开侧栏的操作入口。

## 能做什么

- 可选学习模式：在翻译卡片手动加入学习库，保存当时的释义、短语义、原句、句译及网页或 PDF 来源，支持检索、笔记、释义编辑和固定间隔复习。

- 默认按住 `Alt` 悬停约 450 毫秒，查看单词的简短中文义项。网页中离开目标词或松开触发键时自动收起，单词卡片有约 500 毫秒的移入缓冲，便于操作判断依据、收藏及反馈；滚动仍收起。PDF 阅读页中卡片保留到点击卡片外或按 `Esc` 关闭。划选句段的翻译仍点击卡片外关闭。每个网站需在扩展弹窗中单独开启。
- 按住 `Alt+Shift` 悬停翻译当前句子；拖拽选中句子或自然段，松开后自动翻译。可在弹窗或设置中关闭选中自动翻译。
- 结合原句判断词义、识别短语；内置候选义只辅助句意对齐，不读取用户主题词库。
- 开启学习模式后可手动收藏单词、短语、原句和来源；英语、法语分别保存并可复习、发音。
- 从 Edge / Chrome 中打开的 HTTPS PDF 点击弹窗底部“PDF”，可在 HoverGloss 阅读页重新打开；也可导入本地 PDF 或粘贴 HTTPS 链接。阅读页支持有文字层的 PDF 按键悬停单词和选中句段翻译。

## 安装与试用

### v0.9.28：播放器一次点击开始双语字幕

打开字幕模式后，播放器显示“开始双语字幕”。点击后直接在视频页面准备本机翻译，完成后自动开始；首次语言包下载会显示进度，之后重用已准备的模型。不再需要勾选 CC 确认、点侧栏准备、再回侧栏点开始。停止后保留画面开始按钮，便于重新开始；暂停与继续仍可在画面或侧栏控制。

YouTube 会在开始时尝试开启 CC；当前版本不自动选择字幕语言，没有英文时需在播放器菜单选择英语。B站需开启可读取的英文 CC。仅打开控制面板不会下载模型或启动翻译。无 CC 听音模式保留独立模型准备和音频授权流程。本节替代旧版多步 CC 准备流程。

### v0.9.27：字幕控制面板跟随视频页

控制侧栏仅在 YouTube / B站支持的视频标签页启用，切换至其他网站时由浏览器隐藏。新增“收起控制面板”，收起后画面英文 CC 翻译继续，可从播放器暂停或停止，或通过扩展弹窗重新打开控制面板。仅侧栏模式点击收起时切为画面字幕，以便继续观看。

切换标签页保留 CC 采样、翻译和最近 80 条记录；后台执行速度受浏览器节流、视频播放及 CC 更新影响。手动暂停/停止、切换视频、刷新和关闭视频仍结束或暂停处理。本机听音模式仍依赖侧栏，隐藏时停止。更新后需重载扩展并刷新视频，重新手动开始一次。本节替代旧版关闭侧栏停止、后台暂挂 CC 的说明。

### v0.9.26：移除个性化主题词库

移除阅读主题、主题快捷选项、补充词库、管理/导入/导出入口、卡片的主题保存按钮、自定义专业术语和未启用的研究型 Agent 占位。后台不再生成、读写或优先使用个人主题词条，AI 请求也不再包含阅读主题。旧“仅本地术语”设置自动按浏览器本机翻译处理，即使存有 AI 密钥也不自动启用 AI。

英语和法语学习库及已有记录保留。旧主题 IndexedDB 和旧自定义设置不自动删除，但不再使用；旧词库页地址仅显示移除说明。内置的词义候选、常见义和句子/短语对齐仍用于上下文翻译。本节替代旧版本关于个人词库优先级的说明。

### v0.9.25：切换标签页后恢复 CC 双语字幕

已开始的 YouTube / B站 CC 会话在视频标签页隐藏时改为暂挂，停止读取与提交翻译，保留准备状态、同一视频会话、最近 80 条已完成配对和字幕显示设置。回到同一视频自动从当前 CC 恢复，不回填后台期间错过的字幕。画面模式可在侧栏未重开时恢复；仅侧栏显示模式等待侧栏重连，之后沿用会话。手动暂停、停止、换视频、刷新或关闭视频页不自动恢复，无 CC 听音识别仍须手动重启。

更新扩展后请刷新 YouTube 视频一次，重新开始 CC 字幕；切到其他网站，再回原视频验证。只检查了本次 CC 生命周期与听音停止回归；Edge 使用离线播放器、模拟可见性、CC 和模型验证恢复后的画面，尚未实测登录态 YouTube 的真实字幕及语言包表现。不新增权限、网络服务或本地存储项。旧版章节中“切标签页停止并清空”的行为由本版替代。

### v0.9.24：免费离线基础语法提示

法语学习库和复习答案自动显示“免费 · 离线”语法区，无需接口、联网或下载模型，不设调用次数额度。已有法语记录只要保存了原句即可使用；提示由本地规则即时计算，不重复保存大段解析或改变原记录。

覆盖词表内常见动词的现在时、未完成过去时、简单将来时、条件式现在时词形，及部分助动词＋过去分词、aller＋不定式结构；提示附近的代词或可能的名词短语主语、否定、省音、冠词与缩合。仅靠词尾不猜生词，不将宾语和表语自动定性；同形词、从句或未覆盖词形明确保留不确定性。因此它是入门提示，不是完整的法语句法分析器。

“AI 详细解析”默认收起，无接口也能使用上方离线提示；只有主动点击 AI 解析按钮才发送原句。已有 AI 解析和进行中的请求会展开显示。更新扩展并重开学习库即可查看，不需要重新收藏单词。离线规则与页面流程已定向测试，未做真实语料准确率评测。

### v0.9.23：法语原句语法解析

法语学习库的原句下方新增“句子语法 · 初学者”。点击“配置 AI 接口”，填写兼容接口地址、模型、密钥并保存，回学习库刷新列表。可以保持日常翻译使用本机模式，语法解析单独手动调用 AI。

点击“解析语法（发送原句至 AI）”才发送本条原句，解释每句主干、各成分作用、动词原形与时态，并提供常见结构、易错点与学习提示。服务商可能收费或限额；浏览器本机翻译语言包不具备语法分析能力。本版不提供无需接口的完整语法解析。

解析结果随法语记录保存在本地，重新打开、切换记录和复习不自动请求；复习显示答案后可查看。导出 JSON 包含已保存的解析；手动重新解析会再次发送原句，失败则保留原结果。解析不改变笔记、单词释义和复习进度，旧记录有原句即可使用。AI 可能判断错误，引用原文及覆盖检查不代表语法正确性已验证，可在笔记记录纠正。每库仍最多 1000 条且约 6 MiB，语法解析会增加占用，可能先达到容量上限。

### v0.9.22：法语翻译与独立学习库

在扩展面板选择“法语 → 中文”，并在当前网站启用翻译。首次请进入设置，选法语后点击“下载并启用本机翻译”，再保存；也可使用已经配置的 AI 接口。支持 é、è、ç、œ、重音组合字符及 l’école 等撇号词，Alt 悬停查词、Shift＋Alt 查看句译，也可拖选句段翻译。语言为手动选择，不自动猜测；换回英文文章时请切回英语。

开启学习模式后点击“加入法语学习库”，记录释义、原句、句译、网页标题和链接；可播放单词、短语和原句。学习库顶部可切换英语／法语，查找、复习、编辑、删除、导出均只作用于当前库。两库使用独立存储键，旧英文记录直接保留，各库最多 1000 条，总存储仍受浏览器容量限制。

发音按词条语言选择本机声音；可沿用用户已开启的在线发音许可，无对应声音时提示准备，不使用另一语言的声音代读。翻译模型和朗读声音分别准备。法语本机模式提供单词机译与整句参考；现有英文词库、常见义和实验性英中对齐不用于法语，配置 AI 时可按整句判定义项，译文仍需核对。扫描 PDF 的 OCR 语言包目前仍为英语和简体中文，本版未增加法语 OCR 包。

本机法中可用性通过浏览器的语言对检测确定，见 [Chrome Translator API 官方说明](https://developer.chrome.com/docs/ai/translator-api)。离线 Edge 测试验证了法语取词、收藏和双库复习、发音语言选择；翻译与声音提供方为测试桩，尚未验证用户设备上的真实法中模型或音频质量。

### v0.9.21：扫描 PDF 识字后翻译

扫描页点击“OCR 识字”→“重新识别当前页”，完成后回到原页，可 Alt 悬停查词、拖选句段翻译。“整理当前页”仍可核对并复制识别文字。识别结果按单词位置覆盖原图，悬停上下文使用 OCR 段落边界。框选识别只为本次选定区域生成文字层，替换该页上一次识别结果；整页阅读请选择识别当前页。

当前阅读窗口在内存中保留最多 8 页识别结果，缩放和翻回这些页面可直接复用；关闭对应文件或阅读窗口会释放，不写回 PDF。识字仍在本机完成，翻译由既有翻译设置决定。无可靠文字位置时只提供复制预览，不制造悬停位置；错字、复杂排版和模糊扫描仍会影响译文。未加入扫描目录识别。

### v0.9.20：B站英文 CC 与双语字幕比例

增加桌面 B站 `bilibili.com/video/BV…`、`/video/av…` 的可见英文 CC 适配，包括 `p` 分P标识。弹窗可打开双语字幕侧栏，准备/确认/主动开始流程同 YouTube。B站默认“统一双语”：保留可读取的原 CC 更新，视觉隐藏原英文，再在同一播放器内显示英文在上、中文在下。中文默认英文的 90%，可选 80%/90%/100%；基准英文小/中/大配合播放器高度缩放。长句换行，正常播放器每种语言最多两行，小播放器最多一行以控制遮挡；完整文本可回看侧栏。相邻两种语言间距约 4px。原生英文＋中文模式不修改网站英文大小；要同时调整英文请选统一双语。

更新原扩展目录、重新加载并刷新 B站视频。先在播放器开启可选的英文 CC，再从 HoverGloss 弹窗打开字幕侧栏，准备本机翻译，在画面点击“启用本机翻译”，勾选英语确认并开始。字号、中文比例与字幕底距均可调；播放器内部子区域全屏时会把字幕层移入该区域，保持已完成译文，不重复初始化模型。原生字幕样式、幻灯片正文、弹幕与其他插件字幕不修改；停止/失败时恢复原生显示。

限制：仅文字层 CC，不会 OCR 视频画面或抓取字幕后台接口。截图中压进视频的英文、橙色中文或其他插件生成的字幕无法保证接管；需要先关闭重复插件字幕。没有可读取英文 CC 时明确提示，不自动听音或申请权限。B站直播、番剧、嵌入播放器暂不支持；无 CC 听音仍限 YouTube。现有强制/可选权限不变，主机范围未扩大，不上传字幕。

定向检查包括平台/分P识别、入口、比例与大小、换行、播放器内布局、子区域全屏、停止恢复，以及原 YouTube 字幕/音频生命周期回归。离线 Edge 的 B站 DOM、CC、模型结果和端口为可控样例，尚未验证用户真实 B站视频；视觉样例为 `test-results/bilibili-captions-v0.9.20.png`。

### v0.9.19：视频页 CC 会话与滚动字幕修复（历史版本）

修复全屏导致侧栏文档销毁、重新打开后回到 0 条字幕的问题。已有 CC 的模型、串行推理、最近 80 条已完成英中配对及显示设置改在视频页内存维护；侧栏只控制和展示，重连不会再下载模型或重复翻译历史。无 CC 听音识别仍由侧栏负责，隐藏即停止，不迁移音频采集。

更新原扩展目录并重新加载，刷新 YouTube。打开字幕侧栏，点“准备本机英中翻译”，再在视频画面右上方点“启用本机翻译”（需要该文档的用户点击）。就绪后回侧栏，确认英文 CC 并点“开始”。仅准备不会读取 CC。已勾选“全屏时继续”、选择画面字幕且前台播放器处于 DOM 全屏时，即使侧栏断开/被销毁，翻译也能继续；播放器提供暂停、停止按钮。退出全屏后的侧栏重连有约 1 秒宽限，未重连则停止。普通隐藏、关闭侧栏、视频页隐藏/切标签页、换视频或刷新仍停止；不会自动在新视频开始。

连续滚动 CC 不再必须等到文字安静 500ms：约 500ms 稳定或最长约 1.25 秒触发一次快照；只有一个进行中的推理与一个最新待处理快照。英文继续变化不取消已提交的配对，结果带自己的源英文；跨句时标注“上一句”。超过约 8 秒且已不对应当前英文的结果跳过，显示落后提示。拖动、广告、CC 关闭、暂停或停止作废旧结果；失败有提示并有限频重试。最近 80 条是已完成快照，滚动改写可能使相邻记录重复部分英文，不保证逐字完整转录或零延迟。

### v0.9.18：中文慢读、英文平滑与 CC 全屏继续（历史版本）

使用步骤：

1. 新版文件更新到原扩展目录，在扩展管理页重新加载并刷新 YouTube，不卸载或清空已有学习数据。

在线播放时按钮标明“在线播放中…”。关闭开关会停止当前在线朗读和等待中的任务；另一个已打开的网页、PDF 或学习库也监听设置变化。本机声音播放失败不会自动切换在线；在线失败不会自动重试或调用其他服务，只显示错误供用户手动重试。不改系统设置、不增加扩展权限、不动已有学习记录。

重新加载原目录中的扩展，并重开学习库或已有阅读页后试用。定向模拟检查覆盖发音许可、存储、撤回、延迟任务及学习库交互；尚未验证真实 Edge 在线语音能否成功播放。下面旧版本说明中的“仅本机”对应当时版本，现由本节的可选开关扩展。

### v0.9.8：发音检测与错误提示修正

学习库增加“发音检测”，手动检测后列出浏览器实际提供的声音名称、语言和本机/在线状态。检测不播放声音、不下载语音、不修改系统、不保存或上传检测结果；来源未确认或在线的声音仍不使用。发音失败会展开检测入口。

语音准备由原来的 1.5 秒改为最多 5 秒，并同时监听事件及轮询；区分空列表、没有英文、只有在线英文、来源未确认、读取失败及已找到声音但播放失败。系统有英文桌面语音，不等于浏览器接口能读取它。Chromium 的 Windows 实现优先枚举 OneCore，失败后才尝试旧 SAPI 列表，因此英文只在旧列表时可能不可用；不能靠延长等待解决。若检测缺少本机英文，需在 Windows“时间和语言 → 语音 → 管理语音”添加标准英语语音，再重开浏览器。本版不绕过系统限制，也不宣称已经恢复实际 Edge 发音。参考：[Chromium 实现](https://chromium.googlesource.com/chromium/src/+/HEAD/content/browser/speech/tts_win.cc)、[微软语音安装说明](https://support.microsoft.com/en-us/accessibility/windows/narrator/appendix-a-supported-languages-and-voices)。

更新原来已加载的扩展目录后重新加载，并重开学习库；不要卸载扩展或清除数据。只做发音及学习库对应修改的定向模拟检查，实际声音仍需设备验证。

### v0.9.7：学习发音与单词关联短语

开启学习模式后，单词及已识别的短语旁会出现“▶ 发音”；学习库详情和复习中也可播放。仅点击才朗读，优先选择设备默认的本机英文语音，不使用在线语音、不消耗翻译接口额度，也不保存音频文件或伪造音标。没有可用本机英文语音时会提示在系统语言/语音设置安装后重开页面；英中翻译语言包不等于英文朗读语音。

单词卡片的短语区域增加“词与短语一起收藏”。它与顶部收藏按钮保存到同一条语境记录，不把短语拆成孤立条目；单词义、整短语义和不确定性标记仍分别保存。先收藏单词、后出现短语时，可以补存短语，保留已有释义、笔记和复习进度。同一语境最多关联 20 组短语译义。

直接划选 2–8 个英文单词且不超过 100 字、没有句末标点的短内容时，学习模式会提供“收藏为关联短语”。它不是自动认定固定短语：需要你主动选择关联单词，可填写单词义；留空时保存为“待确认”。短语译义不会被用作单词义，也不会把选中短语的译文冒充整句译文。尽量复用目标位置的原句提取，保留 PDF 文件名、页码或网页来源；取文不完整时仍需核对。

学习库在同一个单词详情里集中显示关联短语，支持按短语英文或中文义检索，也会一起出现在复习答案中。旧记录可继续使用；后补短语不会重置复习。更新时建议更新原来已加载的扩展目录再重新加载，避免因目录变化产生另一份独立本地数据。实际 Edge/PDF 声音与交互效果尚待试用；本次仅做对应功能及相关卡片/取文的定向模拟检查。

### v0.9.5：问题反馈与报告对比

单词卡片底部增加“释义不对”。点击后卡片固定，可选择单词义、短语、原句提取、整句翻译或其他问题，并填写可选说明；只有点击“保存问题”才记录当时的原句、目标词位置、卡片译文与来源。异步对齐结果不会改写正在填写的快照。完成、点击卡片外或按 Esc 可退出。此功能不自动改写释义，也不额外请求翻译或上传反馈。

弹窗 → 测试 → “查看与导出问题记录”，可筛选、删除或导出本机记录。最多保存 200 条且不超过 2 MB；满额后提示整理，不自动删除旧记录。导出包含原句、网页链接或 PDF 文件名和页码，分享前请核对。

“比较两份评测报告”可导入质量检查页导出的两份 JSON，按同一原句、目标词位置及主题匹配。单词、句意和短语分别比较人工判断，列出改善、退步、混合变化与待确认；未复核、仅短语可理解或不确定不算准确率提升。导入只在页面内存处理，不覆盖当前评测，可导出对比结果。本版未更换翻译模型，尚无真实准确率提升结论。

### v0.9.4：固定评测与通用词义判断

在扩展弹窗点击“测试”，再打开“翻译质量检查”。100 个原创例句分别标注目标位置、参考单词义与短语义，覆盖多义词、SQL、数据分析、资产评估、供应链等 10 组场景。点击“准备本机翻译”后可分组检查，记录独立机译、上下文结果、整句译意和复核状态；结果在本地保存，可续测、人工复核并导出 JSON。参考命中只用于筛选，不能作为真实准确率。评测固定使用内置候选词库，不调用 AI，不改变日常设置；可选择使用已经启用的本机对齐。详细范围与步骤见 [评测说明](EVALUATION.md)。

本次通用判断调整：整句有译文时，未出现在句译中的候选降低排序；不同候选义都出现在同一句时，保留低把握并允许模型复核，不能仅凭“中文包含这个词”跳过复核。已明确识别的短语保留原来的专门证据，但词库只提供整短语译义时也明确标为“短语义”，不作为目标单词的独立对应。缓存保留原文大小写，并复用同一句的本机译文与正在进行的请求。旧的 20 条人工译文诊断样例从 12 条命中到 13 条，不能推算真实模型准确率；本机真实评测尚待运行。

### v0.9.3：搜索入口与待确认词义

搜索框为空或只有英文时不显示搜索助手；输入中文并完成选字后，只显示小巧的“转英文”按钮。点击才展开面板。手动模式在展开后生成候选，面板同时显示原始中文和英文候选；收起会取消当前任务，回到小按钮。启用自动替换后，在语言包就绪时可保持小按钮并自动翻译，成功后显示“已转英文”，点击可恢复中文。打开面板后仍可启用当前平台或准备语言包。窄窗口中的面板可滚动。

词义未确认时，卡片先提示状态；已定位短语时先显示带英文的短语义，再显示单词常见义或未确认参考。没有可靠短语时，优先显示可用的整句译意。可靠的单词句中义仍保留原来的简洁展示，学习库保存的词义与短语字段保持各自独立。这次改进显示与不确定性标记，不更换模型，也不宣称实际翻译准确率提高。相关模拟交互和短语案例检查通过；真实网页和本机模型输出仍需试用验证。

### v0.9.2：多平台英文搜索试验

在原 YouTube 基础上，新增 Google、Bing、Reddit、GitHub、Stack Overflow、Wikipedia 的主要搜索框适配。仅识别平台特定的搜索输入或搜索表单，不处理评论、聊天、密码框、发帖编辑区和不明用途的输入框。开关默认关闭，各平台分别保存；原 YouTube 开关保持原值。可从扩展弹窗开启，也可输入中文后点击“转英文”，在展开的 HoverGloss 面板开启。

Google 支持 .com、.com.hk、.co.uk、.co.jp、.ca、.com.au、.de、.fr、.co.in、.com.sg 的主域名及 www 域名；Bing 支持主域名、www 和 cn；Reddit 支持主域名、www 和 old。Wikipedia 支持主站及常见语言站，功能不会切换站点语言，查找英文条目建议在 en.wikipedia.org 使用。GitHub 主要适配全局搜索，Stack Overflow 适配 /search 表单。Google 的搜索 textarea 和 Reddit 等平台可访问的开放 Shadow DOM 搜索输入均有处理；闭合 Shadow DOM 或平台页面改版可能暂时无法识别。

首次使用点击面板“准备中译英”，直接在当前页面创建浏览器本机中文→英文翻译器，可能需要下载语言包。已有英译中语言包不等于此页面的中译英已就绪；每次完整刷新页面后需重新点击准备，站内切换页面通常可复用。当前设备或页面环境不支持时会显示错误，本版不会自动改用付费或公共翻译接口。

输入中文或中英混合搜索词，完成输入法选字后，手动模式需展开面板，再停顿约 800 毫秒生成英文候选。默认点击“替换为英文”才填回搜索框；勾选“自动替换”后可在面板收起时直接填入。两种方式都不自动提交搜索，按回车仍由网站正常处理。点击“恢复中文”可撤销最近一次替换；如果你已继续编辑英文，为避免覆盖新输入，不再提供该次恢复。

输入改变、开始选字、离开搜索框、收起面板、页面地址变化或提交搜索后，旧结果不再回填。超过 15 秒仍未返回时保留原文并提示重试。自动替换若发现英文术语或数字缺失，会退回候选预览要求核对；检测到 repo:、site:、引号或方括号等搜索语法时，也强制先预览。该检查不能保证语义正确或搜索条件完整保留。搜索词最多 300 字，翻译仅做忠实中译英，不额外扩写搜索意图，也不保证搜索结果全部为英文。

当前版本已完成各平台识别规则、设置隔离、开放 Shadow DOM 事件，以及 Google / YouTube 模拟输入框联动检查；尚待实际 Edge 中各平台页面验收。

### 加载扩展

1. 下载本仓库源码，或克隆仓库到本机。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，选中**包含 `manifest.json` 的本目录**。
4. 打开普通英文网页，点击 HoverGloss 图标，为当前网站开启翻译。默认按住左侧 `Alt` 键悬停在英文单词上。
5. 点击弹窗底部的“测试”可打开自带测试页，分别尝试 `query`、`return`、`order`，以及拖拽选中整句。

源码修改后，请在扩展管理页点击“重新加载”，再刷新要测试的网页。浏览器内置 PDF、扩展商店等受限页面可能无法注入本扩展；这不是图片识别功能，也不承诺在这些页面工作。

### 阅读 PDF

**PDF 干净复制**：打开 PDF 后点击“整理当前页”，或先选中文字再点击“整理选中文字”。面板对照显示提取原文与可编辑的整理结果；默认按常见横排分栏重排、合并段内断行、清理多余空格与常见英文连字，保留段落。行末连字符默认保留，确认属于断词时再勾选“连接行末断词”。复杂排版可切换“原始存储顺序”，也可关闭断行合并或直接编辑结果，再点击“复制整理结果”。只处理当前页或选区，翻页、缩放、切换文件会清空旧预览；整理过程在本机完成，不调用翻译或上传文字。

整理规则只处理文字正确但排版混乱的情况。发现异常字形时会提示疑似乱码；无文字层时会提示可能是扫描图片，可点击“OCR 识字”绕过原文字层重新识别。排版规则不能恢复错误字符，也不能保证检测出所有乱码；翻译卡片正常仅说明相关文字可用。OCR 结果同样需要核对，表格、公式、竖排、从右到左文字和复杂图文排版尤需注意。PDF 存储顺序可能不同于阅读顺序，参见 [PyMuPDF 官方说明](https://pymupdf.readthedocs.io/en/latest/recipes-text.html)。

Edge 内置 PDF 阅读器不能直接显示 HoverGloss 的翻译卡片。打开 PDF 后点扩展的“PDF”入口，会在**新的 HoverGloss 阅读页**重新加载该 HTTPS 文件；原标签页不会被替换。若原文件位于本机，点击阅读页的“打开本地 PDF”并重新选择文件；无需打开“允许访问文件网址”。也可手动粘贴 HTTPS PDF 链接。在线读取会向原 PDF 站点请求文件，并在需要时带上该站点的登录 Cookie；PDF 内容在本地解析，不会整份上传到翻译服务。只有你触发的词句会按翻译模式发送。单份 PDF 上限为 60 MB。

阅读页可同时打开最多 8 份 PDF，通过文件标签切换并保留各自的页码、缩放和目录状态；关闭标签会释放该文件占用的内存。关闭阅读页后，扩展仅记住文件指纹、页码和缩放；重新打开同一文件且上次页码大于 1 时，先询问“继续阅读”或“从第 1 页开始”。本地文件需重新选择，在线文件需重新打开链接，扩展不会保存整份 PDF。PDF 自带书签时左侧会显示分级章节目录，点击可跳到目标页。没有内置书签时，目录侧栏可按需检查前 40 页，从普通文字层或 PDF 内可跳转目录按钮中提取条目；若目录在第 40 页之后，可翻到目录页，点击“将当前页识别为目录”。按钮目录优先使用 PDF 自带的跳转目标，无需估算页码差；普通文字目录会用 PDF 页码标签或正文标题估算差值，仍需核对，不准可手动调整。识别只在本地进行，不会自动联网搜索或调用 AI。确认后可点击“保存本地目录”，下次打开同一文件自动载入，也可在侧栏删除。顶部仍可输入 PDF 页码并回车跳转。阅读页未聚焦输入框且未选中文字时，`←` / `→` 可上一页 / 下一页。扫描版、纯图片页可按需 OCR，完成后在原页悬停或拖选翻译；不支持自动识别图片中的目录。受密码保护、跨域登录或特殊 PDF 可能无法打开。网页地址不是以 `.pdf` 结尾时，可在阅读页粘贴原 HTTPS 链接尝试打开。浏览器自带 PDF 阅读器里的直接悬停仍不支持，需使用 HoverGloss 阅读页。

## 翻译来源与隐私

| 模式 | 发生什么 | 网络传输 |
| --- | --- | --- |
| 浏览器本机翻译 | Chrome／Edge 自带模型翻译词句，英语结合句意和短语对齐判断词义 | 首次由浏览器下载对应语言包；翻译文本不离开设备，无需密钥或额度 |
| 智能模式（默认） | 完整配置 AI 时结合整句消歧；未配置或 AI 暂不可用时使用浏览器本机翻译 | 本机模式不上传文本；AI 模式发送目标文本和所在句子 |
| 句子优先 AI | 先理解整句、识别固定搭配，再返回目标词在当前句中的义项 | 发送目标文本、所在句子和少量内置候选义，并向该服务商发送你的 API 密钥以认证 |

MyMemory 已完全移除。免费后备服务改为浏览器内置 Translator API：Chrome 138+、Edge 148+ 桌面版可用，首次使用需在设置页点击“下载并启用本机翻译”。普通网页与 PDF 会优先使用扩展自身的后台翻译页面；若浏览器要求在当前用户触发的网页环境中创建翻译器，则自动在页面内重试。`downloadable` 状态不再直接等同于语言包缺失。它会在本地分别生成目标词译文和整句译意，但不能像大语言模型一样可靠地把每个多义词与句子成分对齐；严格的语境消歧仍建议使用句子优先 AI。上下文 AI 会在一次请求中返回目标词义、词性、所属短语和整句译意。相同翻译会在扩展内短时缓存。普通网页中被链接、粗体等行内元素拆开的句子会先合并，再提取当前句。

浏览器本机模式采用句子优先判断：内置候选义辅助对齐，系统先翻译完整句子，再根据上下文规则、完整短语和中文译文中的实际片段选择目标词义。悬浮卡会显示识别短语、句中对应片段和高／中／低匹配线索；这些等级不是准确率。低匹配时保留其他可能译义。自 v0.9.26 起，个人主题词库与自定义术语不再覆盖翻译结果。

v0.8.4 试验更新合并相同译义的证据，缩小目标词附近的搭配判断范围，并补充常见多义词。弱证据结果显示“可能是”。受控样例的评测过程和限制见 `ACCURACY-PILOT.md`。

v0.8.5 增加可选的本机词语对齐增强。在“翻译设置”点击“下载并启用对齐模型”后，会从 [Awesome-Align 量化模型仓库](https://huggingface.co/cstr/awesome-align-onnx-int8)下载约 150 MB 的权重，连同少量配置文件缓存在浏览器扩展自己的 Cache Storage；对齐运行代码随扩展打包。普通悬停先显示原译文，只有整句翻译存在、现有词义判断把握较低时，才在后台尝试英中词语对齐并更新卡片。关闭勾选项即可停用；模型缓存可能被浏览器清理，届时原有翻译仍可用，重新点击下载按钮即可恢复。它只帮助定位译文片段，不能修正错误的整句译文，也不保证每个多义词更准确。目前仍属实验功能。

v0.8.6 对低匹配结果增加保守的句意复核：先显示原候选，再让可选本机模型寻找目标词在整句译文中的对应片段。只有双向对齐、与其他片段区分明显且不是常见虚词时才更新释义；证据不足会明确标为“待确认”。卡片区分初步匹配线索与复核状态，不把模型相似度冒充翻译准确率。未启用模型时仍可快速翻译，但无法保证低匹配词自动得到句中释义。

v0.8.7 修复设置页显示模型就绪、悬停时却因“仅从本地读取”配置冲突而报不可用的问题。“重新测试模型”现在还会通过后台执行一次示例词语对齐；仅加载成功不再算通过。已有缓存通常不必重新下载，但仍需在扩展管理页重新加载并刷新网页。若后台测试失败，设置页会显示具体错误，普通翻译不受影响。

v0.8.8 允许已知短语分别提供整个短语译名和目标词的简短义项。例如 `European Commission` 中悬停 `Commission`，显示“委员会”，另列“European Commission → 欧盟委员会”；`sales commission` 仍可显示“佣金”。这是明确收录短语与语境候选的改进，不代表能自动拆解所有未收录的专有名词或意译短语；不确定时仍保留待确认提示。

v0.8.9 试验把本机对齐的中文侧从“只取一个分词片段”改为“连续汉字片段”，并为相邻大写英文词及部分动词—名词—介词搭配尝试定位整短语。若只能定位短语，卡片显示“短语义”并标注单词义待确认；低匹配且整句译文不支持孤立词义时，完成复核后不再把它作为主结果。这是可回退的实验逻辑，尚未在真实 Edge/Chrome 的模型输出上完成准确率评测，不能保证所有专有名词或习语都能拆出单词义。

v0.8.10 将短语候选扩展到普通相邻实词，而非仅靠专有名词或少数结构。本机对齐会检查相邻词是否共同对应中文片段；若单词仍无法定位，最多再用浏览器已有的本机翻译器试译 3 个相邻短语，只有短语译文在整句中唯一出现时才显示“短语义”。例如 `prime minister → 总理` 不应把“总理”硬归给 `prime`；能可靠拆分时仍显示单词义与短语全译。额外试译仅在低把握且对齐失败时触发，不新增外部翻译请求、词库或模型下载；真实浏览器准确率仍待验证。

v0.8.11 调整短语结果卡片：顶部并列显示目标单词的释义或未确认直译，以及带完整英文的短语释义。整短语意译不会只写在单词标题下；判断依据和句意仍保留在下方。这是显示优化，不改变翻译判断。

v0.8.12 将单词的独立机译与常见义分开。少量高频多义词有本项目人工整理的简短常见义，例如 `prime` 显示“主要的；首要的”；未收录词只标“单独机译参考（未确认）”，不冒充词典释义或句中义。这份小表不是完整词典，也不参与上下文译义判断。卡片默认只显示词义、短语义和句意；匹配线索及复核过程可点击“查看判断依据”展开，展开状态在同一次异步复核中保持。

v0.8.13 修正“单独机译参考”的来源标注：它只显示浏览器本机翻译器对目标单词单独翻译的原始结果；语境筛选后的其他候选义另标为“初步候选”。悬停卡片不再因鼠标移开或页面滚动而自动消失，可移入卡片查看判断依据；点击卡片外或按 `Esc` 关闭。继续悬停别的词时会更新卡片。

v0.8.14 改善网页标题的上下文边界：栏目标签、眉题与正文标题若属于不同视觉文本组，不再拼成同一句发送翻译；标题内部的普通行内样式仍会合并为完整标题。PDF 文字层沿用原有提取方式。

v0.8.15 修复 PDF 阅读页将整页文字连成一句的问题。现在按文字坐标、字号、行距、缩进和分栏先划分文本块，再提取目标词所在句子；不同文本块之间不再因缺少句号而相连。普通段内换行可继续合并，坐标缺失或排版无法确认时只使用当前文字片段。判断依据中增加“原句”，便于核对实际用于翻译的英文。复杂杂志排版仍可能被保守地拆成较短片段，需要结合原句检查。

v0.8.16 在 PDF 阅读页增加多文件标签、每份文件独立页码与缩放，以及下次打开同一文件时的续读选项。阅读位置按 PDF 指纹保存在浏览器本地；不保存 PDF 原文件，因此本地文件下次仍需重新选择。

v0.8.17 区分网页与 PDF 的悬停卡片：网页移开目标词、松开触发键或滚动后自动收起；PDF 保持点击卡片外关闭。网页移向其他词时先清除旧卡片，再按已有悬停延迟翻译新词；已收起的卡片不会被迟到的翻译结果重新打开。划选、双击等主动触发的翻译保留原关闭方式，触发模式设置不变。

v0.9.0 增加学习模式与独立学习库。学习模式默认关闭，可在扩展弹窗、PDF 阅读页或学习库中开启；只有点击卡片“加入学习库”才保存。网页学习模式提供 500 毫秒移入卡片的缓冲，进入卡片后可点击收藏，离开后自动收起；PDF 保持原交互。普通模式仍即时收起网页悬停卡片。

学习库按“单词 + 原句 + 来源 + 页码”去重，同词在不同语境中分别保存，不会覆盖已编辑释义或复习进度。记录包含收藏时的显示释义、待确认标记、可用的常见义和短语义、原句及句译、翻译来源、网页标题/链接或 PDF 文件名/页码。它不是完整词典，也不会额外调用 AI；未确认释义需自行核对，在编辑区主动确认。所有记录都可检索、编辑笔记、删除或导出 JSON；当前版本暂不支持导入。学习库与已移除的主题词库互相独立，已有学习记录保持不变。

复习时先显示单词和原句，点击显示答案后自评：忘了在 10 分钟后到期；连续记得则依次在 1、3、7、14、30 天后到期（之后保持 30 天），每次作答立即保存进度；这不是自动记忆预测或后台提醒。学习库最多保存 1000 条、约 6 MiB 内容，均保存在当前浏览器扩展本地存储，不跨设备同步。关闭学习模式不会删除记录。本地 PDF 需重新选择原文件并按记录页码跳转；在线来源链接可直接打开。扩展卸载或清除数据会丢失记录，建议定期导出。

扩展在普通 HTTP/HTTPS 页面加载轻量内容脚本，但只有你为某网站开启后才触发翻译。它申请较广的 HTTPS 访问权限，是为了允许用户自行填写不同的 AI 服务商地址；当前版本尚未把这项权限缩小到逐个请求。API 密钥保存在浏览器的本地扩展存储中，不随源码上传；不要在公共电脑配置密钥，也不要将真实密钥或个人数据导出文件提交到仓库。更多细节见 [隐私说明](PRIVACY.md)。

## 已知限制

- Chrome Web Store、Edge 扩展商店等受限页面可能无法工作；浏览器内置 PDF 阅读器不能直接悬停翻译，需要切换到 HoverGloss PDF 阅读页。
- PDF 阅读页的悬停翻译仍只处理有普通文字层的文件；扫描件、密码保护文件和超过 60 MB 的文件不保证可用。目录识别支持普通文字层及带可读外观文字的内部跳转按钮，其他复杂版式可能需要手动跳页。跨页选中文本尚不支持。
- 句子跨常见段落内的链接、粗体等 DOM 节点时会自动合并；结构非常特殊的网页仍可能只能取得局部句子，可以尝试拖拽选中。
- 浏览器本机 Translator API 仅在较新的 Chrome／Edge 桌面版提供；不支持时需自行配置 AI。
- 本机翻译会同时显示目标词译文和整句译意，但对复杂多义词的精确定位仍弱于上下文 AI。
- 可选本机对齐模型体积较大，首次下载和首次加载可能较慢；离线时只有已经缓存的模型可用。模型结果会标为“本机模型对齐（参考）”，遇到成语、短语整体意译或错误的整句译文时仍可能失败。
- 单词/短语最多 6 个英文词；自然段最多约 3,000 字符。输入框、代码块等位置会跳过。
- 尚未有自动化的完整浏览器交互测试；发布前请按 [测试清单](TESTING.md) 在 Chrome 和 Edge 各走一遍。

## 开发检查

直接加载本目录不需要安装依赖，因为浏览器推理代码已打包。修改本机对齐运行代码后，需先安装开发依赖并重新构建；普通源码改动只需运行检查：

```sh
npm run check
```

重新构建对齐运行代码：`pnpm install`，然后 `pnpm run build:aligner`。

检查包括 JavaScript 语法、清单和图标资源、词法规则及后台翻译逻辑。自动测试不能替代真实浏览器验证。

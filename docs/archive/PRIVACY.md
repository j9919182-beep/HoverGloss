# HoverGloss 隐私说明（v0.9.31 预览版）

### PDF 跨页语境（v0.9.31）

PDF 阅读器在显示页面时，可读取同一已打开文件前后相邻页的文字层，用于补全跨页句子。页面布局缓存仅存在当前文件的阅读会话内，最多 6 页；关闭文件后释放。不会自动识别扫描图像，也不会新增外部翻译服务或权限。只有实际翻译时，补全后的句子才按用户已选择的本机或自备 AI 模式处理。

### 本机恢复与显示偏好（v0.9.30）

学习库导入只在用户选择文件并确认后合并到对应语言的本机学习库；预览和取消不写入。备份文件不会上传。已有释义、笔记及复习状态不被重复记录覆盖。字幕显示偏好按平台保存在本机，不包含视频内容，也不保存自动启动许可。切换字幕来源会取消旧模式尚未完成的启动。无新增权限或服务。

本机翻译长句时保留原句；对齐模型对过长句子使用目标词附近的片段及其本机译文，不额外发送到外部翻译服务。

### CC 开关（v0.9.29）

用户在扩展弹窗打开“自动双语字幕”开关，即授权当前视频的英文 CC 本机翻译，可能准备或下载语言包。仅打开弹窗不开始处理。首次若浏览器要求视频页点击，会显示确认按钮；关闭开关会取消准备和处理。状态仅属于当前视频会话，不跨视频自动启用、不采集声音、不自动请求听音权限，无新增权限或上传。收起弹窗后已启动的画面字幕继续。本节更新下方历史版本的侧栏启动入口。

### CC 一次点击启动（v0.9.28）

打开字幕侧栏只显示视频内的开始按钮。用户点击“开始双语字幕”后，才准备英中本机模型并自动开始读取 CC 与本机翻译；首次可能下载语言包。该操作会尝试开启 YouTube CC，不自动选择语言、不启动听音、不请求音频权限。停止会取消未完成的准备或字幕处理，重试需手动点击。旧版额外 CC 勾选确认和单独准备步骤已合并，无新增权限或服务。

### CC 控制侧栏与后台处理（v0.9.27）

视频标签页的侧栏与普通网站隔离，收起面板或切到其他网站后，已手动开始的英文 CC 读取及本机翻译继续运行；浏览器可能限制后台频率。最近 80 条配对仍只保存在视频页内存。用户可通过视频画面的暂停/停止按钮控制处理；换视频、刷新或关闭视频结束会话。本机听音仍在侧栏隐藏时停止，不自动重启。无新增权限、上传或持久翻译历史。本节替代下文 v0.9.25 的后台暂挂行为。

### 主题词库移除（v0.9.26）

不再提供主题生成、管理、导入导出、自定义术语或主题优先匹配，也不再发送主题生成请求。旧主题 IndexedDB 与旧设置保留但不读取、不使用、不自动删除。旧“仅本地术语”模式按浏览器本机翻译处理，不因已存 AI 配置而启用 AI。英语和法语学习库继续独立保存；旧学习/问题记录中已有的主题字段保留，新收藏不再采集阅读主题。

### CC 标签页暂挂与返回恢复（v0.9.25）

用户主动开始的可见 CC 会话在视频标签页隐藏时暂挂：清除采样定时器、作废未完成结果并移除字幕覆盖层，在视频页内存保留会话身份、准备状态、最多 80 条已完成配对及显示设置。回到同一视频后恢复当前 CC，画面字幕可独立于侧栏重开；仅侧栏显示等待连接恢复。页面重新获得侧栏连接后回到正常心跳管理。暂停、停止、导航至另一视频、刷新、关闭不自动重启；后台期间不补采或回填字幕。音频听音模式继续采用原有隐藏即停止、需手动重启的规则。无新增权限、持久存储或外部服务。

### 离线语法提示（v0.9.24）

法语学习库直接在当前页面用扩展自带词形与规则分析已保存的原句，无网络请求、不下载模型、不调用 AI 或朗读服务。提示按需即时计算，不另存结果，不改变学习记录或复习进度；导出的原句可在当前版本重新生成提示。AI 区域只检查本地配置，仍需主动点击解析才发送原句，原许可与说明继续适用。无新增权限或持久存储项。

### 法语语法解析（v0.9.23）

仅在法语学习库点击“解析语法（发送原句至 AI）”或重新解析时，向已配置的 HTTPS AI 接口发送该记录的完整原句及固定教学指令；不附带词条、旧译文、笔记、文件名、链接或其他记录。原句最多 3000 字符。接口密钥作为认证头发给所配置服务商，可能产生费用或受其额度限制。普通本机翻译模式下也可主动使用此功能，点击前有单独提示；不自动切换普通翻译提供商。

打开学习库只读取本地接口配置是否齐全，不向服务商探测或自动解析。重复的进行中请求合并；无自动重试。结果、对应原句、模型名称和生成时间随法语记录本地保存并包含在手动导出中，不单独保存密钥到学习记录。重新解析失败保留原结果；删除记录也删除解析，进行中的结果不会恢复已删除记录。生成的结构化内容仍是 AI 学习参考，不视为人工核对结果。不新增扩展权限。

### 法语翻译与学习库（v0.9.22）

阅读语言由用户手动选择并保存。英中与法中的本机翻译会话、内存译文缓存按语言区分；法语采用现有翻译设置，本机模式不将原文发送给翻译网站，已配置 AI 时主动翻译会按既有说明发送目标文字、原句。原句与链接仅在用户点击收藏后本地保存。

法语学习库保存在独立的 `hoverglossFrenchLearningV1` 存储键，原英文库 `hoverglossLearningV1` 保留；两库各自管理复习、编辑、删除和导出。发音仅选择当前语言的声音，在线发音沿用用户已选择的许可；主动点击原句朗读时，只传入该条法语或英语原句，在线原句仍限浏览器提供的 Microsoft 声音。没有对应语言的声音不会代用英语或中文。无新增权限和账户同步。

## 页面访问与触发

扩展的内容脚本会注入普通 HTTP/HTTPS 页面，但默认不开启翻译。用户需在弹窗中为当前网站单独启用，之后按键悬停、双击或选中文字才会请求译文。默认启用的网站上，拖拽选中至少两个英文单词、松开鼠标会自动触发句段翻译；可随时关闭此选项或停用该网站。

输入框、编辑区域、代码块等位置会尽量跳过。请勿在网银、邮箱、教务系统及含个人信息的页面启用扩展；浏览器对网页结构的判断不能当作敏感信息保护的保证。

## 什么内容会离开浏览器

- **浏览器本机翻译；或智能模式未配置 AI**：目标词、句子或段落由 Chrome／Edge 内置 Translator API 在设备本地处理。首次使用时浏览器会下载对应语言包，但待翻译文本不会发送给第三方翻译网站。
- **可选本机词语对齐**：仅在用户点击设置页的下载按钮后，扩展向 Hugging Face 请求固定版本的多语言 BERT 模型文件并缓存在本机浏览器。模型下载请求不包含待翻译文本；启用后英文句子、中文整句译文和目标词位置只在设备本地参与对齐，不发送给模型托管网站。模型缓存由浏览器的 Cache Storage 管理，可能因清理浏览器数据而删除。
- **智能模式，已配置 AI；或句子优先 AI 模式**：向用户填写的兼容 Chat Completions 服务发送目标文本；翻译单词时还发送所在的完整句子，以及少量内置候选义项。服务会返回当前词义、所属短语、词性和整句译意。请求中的 API 密钥用于服务商认证。

当前版本没有账号、广告或分析埋点，也不会自动上传整页内容，也不再调用 MyMemory 或其他公共翻译接口。用户自备 AI 服务如何存储或处理请求，取决于相应服务商，使用前请阅读其政策。此说明仅描述扩展自身实现，不代表第三方服务的隐私承诺。

## PDF 阅读

“PDF 干净复制”只在当前阅读页本地整理选中文字或当前页文字层，不调用翻译服务或上传文字，不持久保存整理预览；点击“复制整理结果”时才将结果写入系统剪贴板。翻页、缩放、切换文件或关闭阅读页会清空旧预览。

“OCR 识字”只有在用户点击识别当前页，或主动框选并松开后才开始工作。选定页面或区域在内存中渲染为图像，由独立的本地工作线程识别；引擎与英文、简体中文语言包随扩展提供，不联网下载、不发送页面图像或文字，不将 OCR 图像、文字或语言数据写入新的持久缓存。完成、失败或取消时释放识别线程；翻页、缩放、切换文件和关闭阅读页会取消当前识别并清空预览。OCR 不自动调用翻译服务、不自动加入学习库或目录。

v0.9.21 起，识别成功后在页面上附加可选文字层，并在当前阅读窗口内存保留最多 8 页文字、位置和段落结果，支持缩放和翻页复用。关闭对应文件会清除该文件的识别缓存，关闭阅读窗口全部释放；不修改原 PDF。用户随后主动悬停或拖选时，按现有翻译设置处理相应文字与上下文，若选择外部翻译接口则仍适用该接口的数据说明。

点击弹窗的“PDF”后，HoverGloss 阅读页会重新读取当前 HTTPS PDF；手动粘贴链接同理。向 PDF 原站点请求文件时会携带该站点的登录 Cookie，便于打开已登录站点的文档；不会把 Cookie 发给翻译服务。本地导入的 PDF 直接在浏览器里解析。整份 PDF 不会被 HoverGloss 上传或持久保存。对 PDF 文本主动悬停或划词时，目标词句按上面的翻译模式处理；含敏感信息时应使用浏览器本机翻译。

同时打开的 PDF 只在当前阅读页的内存中保留。扩展会按 PDF 指纹在本地存储页码和缩放比例，以便下次重新打开同一文件时询问是否续读；不会持久保存 PDF 内容或本地文件路径。

没有内置书签时，用户可主动点击识别 PDF 的印刷目录。此操作仅在浏览器本地读取前 40 页或当前页的可选中文字，以及目录按钮的文字与内部跳转目标；不会把目录或整本 PDF 发给 AI／翻译服务，也不包含 OCR。用户点击“保存本地目录”后，扩展会以 PDF 指纹为键，在浏览器本地扩展存储中保存目录标题、页码、页码差或直接跳转页；不会保存 PDF 原文件，且可在侧栏删除已保存目录。

## 本地保存

### 问题反馈与报告对比

只有点击单词卡片的“保存问题”才保存反馈。记录含目标词、在原句中的位置（无法确认时留空）、原句、当时的卡片/整句/短语译文、问题类型、可选说明、扩展版本，以及网页标题/链接或 PDF 文件名/页码/指纹；不保存整份 PDF 或本地路径。保存在扩展本地存储，最多 200 条且不超过 2 MB，不自动上传或写入学习库。可在问题记录页删除或导出；导出包含原句及来源，分享前请核对敏感信息。

导入的评测报告及对比只在当前页面内存中处理，不上传、不覆盖已有评测，也不调用翻译模型。主动导出的反馈或对比文件由用户自行保管。卸载扩展或清除扩展数据会删除本地问题记录。

### 翻译质量检查

只有用户在评测页准备并开始后才运行固定例句。评测使用浏览器本机英中翻译，不调用配置的 AI；可复用已启用的本机对齐。例句、模型输出、人工判断、笔记和浏览器信息保存在扩展本地存储，用户可清空或导出 JSON，不会自动上传。报告不包含 API 密钥或其他翻译设置。参考标签不会发送给模型。

### 多平台英文搜索试验

手动模式仅在用户展开“转英文”面板并启用当前平台后生成候选；开启自动替换后可在面板收起时处理中文搜索词。显示小按钮本身不下载语言包或发出翻译请求。

此功能在 YouTube、Google、Bing、Reddit、GitHub、Stack Overflow、Wikipedia 上分别提供开关，默认关闭；启用一个平台不会开启其他平台。启用后仅读取可明确识别的搜索框；中文输入法选字期间不翻译。中译英在浏览器本机模型中执行，首次主动准备可能由浏览器下载语言包，不调用扩展中配置的 AI 服务或公共翻译接口。最近最多 100 条翻译只缓存在当前页面内存，原始中文仅用于本次候选/恢复，不保存搜索历史。各平台开关与自动替换偏好保存在扩展本地存储。用户自行提交搜索时，搜索词仍按网站正常行为发送给该网站；扩展不会阻止网站自身对输入内容的处理或搜索建议请求。

### 无 CC 本机语音字幕试验（v0.9.12）

新增的是可选 `tabCapture`，不是安装时强制授权。默认仍用 CC 模式，不采集声音、不申请音频权限、不加载语音模型。只有用户点击音频授权按钮才弹出浏览器许可；仅授权不会采集。用户须主动选择无 CC 模式、准备两个本机模型、勾选当前标签页声音确认并点击开始，才在侧栏页面申请选定 YouTube `/watch` 标签页的音频流。

只请求 `chromeMediaSource: tab` 的音频、`video: false`，不采集麦克风、画面、其他标签页或系统音频；如果浏览器不支持则失败，不替换输入源。获取流后通过 AudioContext 回传到扬声器以保持视频声音，同时由扩展本地 AudioWorklet 生成 16 kHz 单声道 PCM。整个标签页的广告、音乐及其他声音也可能被采集，而非只截取主播人声。

本机识别只把短 PCM 片段交给扩展自己的语音工作线程，再将识别英文交给本机 Translator。没有云端 ASR/AI/公共翻译兜底，不向服务器提交音频、识别字幕、来源标题或视频 ID。首次点击准备语音模型时从 Hugging Face 下载固定版本权重/配置，下载服务可看到普通网络元数据，但请求不带阅读内容。运行代码及 WASM 来自扩展包内，识别阶段禁用远程模型加载。

模型数据保存在扩展自己的 Cache Storage `hovergloss-asr-v1`，CPU 与 GPU 权重可能分别占用空间；取消/释放只终止工作线程，不清空下载缓存。没有保存音频文件、导出音频、上传或自动收藏；内存分段最多约 8 秒，识别一段并最多保留一个最新待处理片段，迟缓时丢弃旧积压。显示最多 80 条，英中翻译的临时内存缓存沿用字幕模式。

暂停/停止、撤回权限、切换标签页/视频、隐藏或关闭侧栏、音轨结束时停止音频流并清空未提交片段/识别队列；继续或重开均需手动点击，不自动恢复。已经进入本机推理的片段可能处理至结束，但过期结果不再显示；单段超 30 秒停止工作线程及采集。手动释放模型、切回 CC 或侧栏页面销毁会终止识别工作线程。普通停止/隐藏期间模型可能仍驻留内存，用户可以主动释放。

此节扩展了旧版“只读取 CC、不采集音频”的能力，CC 模式本身仍不采集音频；不改变已有在线发音许可、网页/PDF 翻译提供商设置或学习数据。

### 播放器内 CC 双语显示与会话（v0.9.20）

可见 CC 适配增加桌面 B站 BV/av 视频页及分P，不新增强制/可选权限或扩大已有主机权限。字幕脚本在 YouTube 与 B站主站路由加载，连接只读取标题/视频标识；需准备、英文确认和主动开始才读取当前播放器 CC。B站不采集音频，不启动 OCR，不读取字幕后台接口、弹幕、视频像素或幻灯片正文。仅对已知 CC 容器做可逆视觉隐藏与双语替代，不修改其原有行内样式或第三方插件字幕。比例/字号只在当前视频页会话内存维护。无 CC 听音仍限 YouTube，原许可与隐藏即停止规则不变。

用户在侧栏请求准备后，需要在视频画面点击“启用本机翻译”，直接初始化该文档的浏览器本机 Translator。仅准备不读取 CC。确认英语并主动开始后，仅读取当前播放器可见 CC 与播放位置。不会自动开启 CC 或读取隐藏轨道/后台字幕接口。英中翻译在视频页扩展隔离环境运行，侧栏为控制/展示界面，不调用 AI 或远程翻译、不采集音视频或增加权限；语言包首次准备由浏览器下载。显示替代仅使原 CC 容器透明，不关闭更新或修改字幕文件。

当前英文、中文、片段编号、显示设置和会话状态在视频页内存中维护，经扩展端口给侧栏，不上传或持久保存。调度最多一项进行中推理和一项最新候选，历史最多 80 条已完成配对；本机翻译模块另有最多 500 项临时缓存。原始 CC 持续改写时，稳定约 500ms 或最长约 1.25 秒提交快照；跨句中文标注自己的源英文。默认保留原生英文；显示层不自动收词，只有新增的准备/暂停/停止控制条响应其自身点击，不拦截其他视频区域。

“全屏时继续 CC 字幕”默认勾选，仅在用户已开始、选择画面字幕、已勾选且前台视频确实处于 DOM 全屏时，允许侧栏隐藏、断开甚至销毁后继续。视频页保留会话，重开侧栏恢复状态及最近历史，不重复翻译历史。普通前台侧栏关闭和退出全屏仍有约 1 秒重连宽限；标签页切换暂挂与返回恢复按上文规则处理，恢复出的画面会话可独立运行至下一次侧栏连接或手动停止。画面控制条可随时暂停、停止。换视频、刷新或卸载停止，拖动、广告、关闭 CC 清理旧推理结果。无 CC 音频模式隐藏时始终停止采集。画中画不支持。

### YouTube 双语字幕侧栏试验（原 CC 路径）

`sidePanel` 权限用于浏览器侧栏。字幕适配脚本在 YouTube 与 B站主站 HTTPS 路由加载，支持无整页刷新的站内跳转，但只允许 YouTube `/watch` 和 B站 `/video/BV…`、`/video/av…` 页手动开始。连接侧栏时仅读取标题和视频标识，不读取字幕；确认英语、准备本机模型并点击“开始”后，才定时读取当前播放器可见 CC 文本和播放位置。不会自动开启 CC、抓取隐藏字幕轨道/后台接口或采集音频、视频、麦克风。

已完成的英中配对与播放位置通过扩展端口传给侧栏。英中翻译直接使用浏览器本机 Translator，不调用已配置 AI、公共翻译接口或语音服务，不上传字幕；首次准备可能由浏览器下载语言包。标题和视频标识仅用于当前连接，不作为翻译内容或持久记录。

当前侧栏显示视频页维护的最近最多 80 条。不写入扩展存储、学习库或文件，没有字幕导出和跨设备同步。停止保留已完成历史供回看；主动清空、重新开始、换视频清空历史，关闭/刷新视频页释放会话内存。关闭侧栏不等于关闭视频页，历史与模型缓存可保留在视频页直到主动清空或页面卸载。已执行的推理可能完成，但停止后的返回值不再更新会话。

暂停会停止读取并作废未完成推理；手动暂停不视为可自动恢复的标签页暂挂。正常已连接且非全屏场景超过 7 秒未收到侧栏心跳停止轮询，前台断开采用约 1 秒重连宽限；返回后未重连侧栏的画面会话采用上述独立恢复规则。不自动开启新视频或恢复已停止会话。无英文 CC 的直播需另选听音识别；本功能不改变普通网页翻译提供商设置或既有学习发音许可。

### 学习与其他本地数据

英文发音仅在主动点击按钮后调用浏览器 Web Speech API。默认只使用标记为本机服务的英文声音；“允许在线发音”默认关闭，用户需在学习库主动勾选，许可保存在扩展本地存储。开启后仍本机优先；没有可用本机英文时才使用明确标记为远程服务的英文声音。来源未确认和非英文声音不用；设置读取失败时禁止在线发音。

点击单词/短语发音时，扩展只向语音接口传入该目标文字，不附带原句。主动点击学习库或复习页面的“朗读原句”时，则传入该条记录的英文原句（最多 3000 字符，长句按片段顺序朗读），不附带中文翻译、笔记、文件名、网页链接或整篇文章；不点击原句按钮就不会因收藏、切换记录或复习而发送原句。

本机朗读由设备语音服务处理；在线单词/短语发音交给浏览器提供的远程声音，原句在线朗读仅选择浏览器暴露的 Microsoft 在线英文声音，不转发给其他语音提供商。原句按钮旁及设置中明确提示发送范围，其网络元数据和服务端处理受浏览器及语音提供商政策约束。此功能不调用翻译或 AI 接口，不保存音频或朗读历史。停止按钮、关闭页面或在线许可会阻止相应的后续朗读，但无法撤回已发送的文字；失败不自动换服务或重试。声音列表可见不等于播放一定成功。

手动“发音检测”只读取和显示浏览器暴露的语音列表，不播放、不下载、不保存或上传声音列表，不改系统设置；开启在线许可也不自动朗读。

学习记录可在同一语境单词下关联最多 20 组短语及译义，收藏和补存均为手动操作。直接划选短语时需主动选择关联单词；其原句、短语译文与来源按学习库现有方式本地保存，不为收藏额外请求翻译。补存不覆盖已有单词释义、笔记或复习进度，导出 JSON 会包含这些关联短语。

学习模式默认关闭。启用后也不会自动收藏，仅当用户点击“加入学习库”时，才将当时的单词释义、短语义、原句、句译、翻译来源，以及网页标题/链接或 PDF 文件名/页码/指纹保存至扩展本地存储。学习库另存用户笔记、释义修改、收藏时间与复习进度；不保存本地文件路径或整份 PDF，不为学习功能额外发送翻译请求，也不跨设备同步。用户可以删除单条记录或导出 JSON；导出文件含原句及来源链接。关闭学习模式不会删除旧记录，卸载扩展或清除扩展数据会删除本地学习库。

启用的网站、触发方式、学习模式开关、可选对齐开关、AI 接口地址、模型和密钥保存在浏览器的扩展本地存储中；可选对齐模型文件由扩展源的 Cache Storage 保存。旧主题 IndexedDB 和旧自定义术语设置保留但已停止使用。除用户主动保存到学习库、问题记录或运行质量检查的内容外，译文仅在后台内存中临时缓存，不自动持久保存翻译历史。卸载扩展可能删除这些本地数据；学习库和问题记录仍可导出 JSON，导出文件由用户自行保管。

扩展目前申请 `storage`、`activeTab`、`offscreen`、`sidePanel` 和广泛的 HTTPS 主机权限，另声明仅主动开启音频识别时请求的可选 `tabCapture`。`offscreen` 支持本机翻译上下文，`sidePanel` 用于字幕侧栏；广泛的 HTTPS 主机权限用于访问用户自选的 AI 服务商地址及主动准备本机模型的数据下载。未来版本应评估将其改为按服务商申请。安装前可以在 [manifest.json](manifest.json) 查看完整权限。

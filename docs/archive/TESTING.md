- [ ] “整理当前页”对照显示原文和结果；双栏正文按左栏到右栏排列，通栏标题保留在正文前，段落之间留空行。
- [ ] 部分选中句首/句尾、反向拖选与跨行选区，点击“整理选中文字”只包含实际选中的文字。
- [ ] 断词连接默认关闭，勾选后 `inter-` 换行 `national` 变成 `international`；真实复合词须对照原页。
- [ ] 修改整理结果再复制，剪贴板与编辑结果一致；禁止剪贴板写入时，提示手动复制。
- [ ] 翻页、缩放、切换文件或关闭最后一个文件标签，清空旧预览；重载中的页面不能复制上一页内容。
- [ ] 空文字层显示需 OCR 的提示；异常字形显示疑似乱码提示。普通数学符号不应被当成已确认的乱码。

### 本地 OCR（v0.9.14，本轮修改）

运行 `npm run test:pdf-ocr` 核对识别线程的本地资源路径、裁剪坐标、段落映射、初始化期间取消、超时、失败重试和 PDF 页面切换。可选的 `tests/pdf-clean-copy-browser.test.cjs` 使用本机 Playwright 和 Edge，验证真实 PDF.js 渲染、OCR 与扩展页面相同的 CSP，以及全程无外部网络请求。

- [ ] 纯图片 PDF 没有可选中文字时，“OCR 识字”仍可用；默认英文，可切换简体中文＋英文。
- [ ] “重新识别当前页”显示进度，完成后标注来源为本地 OCR；预览可修改后复制。对清晰的生成图片，英文样例识别正确，中文样例存在个别错字，不将置信度当成准确率。
- [ ] 框选时正向或反向拖动均识别框内文字，不包含框外标题；过小范围提示重新框选；Esc、取消按钮和指针中断可以退出。
- [ ] 初始化、识别期间均可取消；取消后可立即重试。翻页、缩放、切换文件和关闭阅读页会释放识别线程，迟到结果不能覆盖新页面。
- [ ] 在窄窗口核对新增 OCR 控件与预览，不检查其他页面；OCR 期间不上传图像、不下载外部语言包。
- [ ] OCR 在 v0.9.21 起支持原页悬停和拖选翻译；扫描目录、表格结构和公式识别仍不支持。
